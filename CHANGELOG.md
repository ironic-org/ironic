# Changelog

## [1.3.0]

### Features

- Core HTTP framework: modules, dependency injection, controllers, routes, middleware, guards, interceptors, and exception filters
- Configuration, structured logging, OpenAPI generation, and in-process testing utilities
- Optional data integrations: SQLx, SeaORM, Diesel, MongoDB, and Redis
- Optional application features: authentication, caching, scheduling, local events, WebSocket, SSE, HTTP client, and MCP
- Optional production tooling: validation, security middleware, compression, metrics, telemetry, resilience, static files, multipart uploads, and serverless deployment
