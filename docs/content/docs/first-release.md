# Ironic 1.3.0

This documentation starts with Ironic 1.3.0 It focuses on the framework's
small, learnable core: modules, dependency injection, HTTP routing, middleware,
configuration, and testing.

There is no migration guide, version history, or engineering blog in this first
release documentation. Start with [Getting Started](/docs/getting-started).
